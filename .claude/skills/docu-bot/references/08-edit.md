# 8단계 · 편집실 — 최종 완성본 제작 (Premiere Pro)

목표: 흩어진 촬영본(생성 영상)·대사·효과음·음악을 하나의 방송본으로 완성한다.

## 8-1. 소재 정리 (편집 전)
폴더를 씬 번호대로 만든다:
```
프로젝트/
  01_영상/  #1, #2, … #14   (씬별 폴더, 파일명 S##-C##-설명-v##)
  02_대사/  S##-C##-L##.mp3
  03_효과음/ 04_음악/ 05_자료/(고증 문서·사진) 06_자막/ 07_출력/
```
채택 테이크만 남기고, 버전 번호가 가장 높은 게 최신이 되도록 한다.

## 8-2. 시퀀스와 트랙 배치
- 시퀀스: 1920×1080(또는 3840×2160), **24fps**, 오디오 48kHz. 생성 영상 fps가 다르면 해석(Interpret Footage)으로 맞춘다.
- 트랙:
  | 트랙 | 내용 |
  |---|---|
  | V1 | 메인 영상(스튜디오·드라마 INS) |
  | V2 | 자료 INS, 인서트 |
  | V3 | 자막·연도 표기·출처 |
  | A1 | 대사(립싱크·V.O.) |
  | A2 | 효과음 |
  | A3 | 음악 |

## 8-3. 편집 순서
1. **대사로 뼈대**: A1에 대사를 대본 순서대로 깔고 길이를 확정한다(라디오 편집).
2. 대사에 맞춰 V1 컷 배치. 립싱크 컷은 프레임 단위로 싱크 확인.
3. V2 인서트로 설명을 대신한다(말하는 동안 자료 INS로 컷어웨이).
4. **J컷/L컷**: 다음 씬 소리를 0.5~1초 먼저 들어오게 해 전환을 부드럽게.
5. 효과음 → 음악 순서로 얹는다. 대사 구간은 음악 덕킹.
6. 색 맞춤: 컷마다 다른 AI 생성 톤을 Lumetri로 통일(바이블의 톤 & 룩 기준). 필름 그레인을 전체에 얇게 깔면 컷 간 차이가 줄어든다.
7. 자막: 대사 자막 + 연도/장소 표기 + 고증 자료 출처. AI 영상에서 깨진 글자·숫자는 여기서 그래픽으로 덮는다.

## 8-4. 믹싱 기준
- 대사 피크 -6 ~ -10dB, 음악은 대사 아래 -18 ~ -24dB, 앰비언스는 들릴락 말락.
- 최종 라우드니스: 유튜브/온라인 **-14 LUFS**, 방송 납품 -24 LKFS(국내 기준 확인).

## 8-5. 출력과 최종 체크리스트
- H.264, 원본 해상도, 24fps, 고비트레이트(1080p 16~20Mbps 이상). 보관용 마스터는 ProRes.
- 체크:
  - [ ] 대사·자막 오탈자, 립싱크 어긋남
  - [ ] 컷 간 의상·조명·소품 연속성
  - [ ] 얼굴·손·텍스트 왜곡 컷 제거 또는 가림
  - [ ] 실사 고증 자료 출처 표기, "AI로 생성된 재연 영상" 고지
  - [ ] 음악·효과음 사용권
  - [ ] 총 길이가 목표와 맞는지

## 출력
요청에 따라: 폴더/파일명 정리표, 편집 순서표(타임코드·트랙·소재), 자막 파일(SRT) 초안, 최종 체크리스트.
