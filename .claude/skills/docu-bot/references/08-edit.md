# 8단계 · 편집실 — 최종 완성본 제작 (Premiere Pro)

목표: 흩어진 촬영본(생성 영상)·대사·효과음·음악을 하나의 방송본으로 완성한다.

## 8-1. 자료 관리팀 — AI 촬영본 체계적으로 관리하기
AI 제작은 컷마다 이미지·영상을 여러 번 뽑기 때문에 소스가 수백 개로 늘어난다. **편집 전에** 정리 규칙을 정하고, 생성할 때마다 바로 제자리에 넣는다.

폴더 구조 (상위는 소재 종류, 하위는 씬 번호):
```
[작품명] 데이터 매니징/
  1. 원고_바이블/        최종 원고(docx), 제작 바이블, 작업 기록표
  2. 이미지_인서트/      #1, #2, … #15, 추가1, 추가2
  3. 영상_촬영본/        #1 … #15, 추가1 …
  4. 립싱크/             #1 … (원본 컷 + 립싱크 결과)
  5. 오디오/             대사/ 효과음/ 음악/
  6. 자료_고증/          실제 문서·사진 스캔, 출처 메모
  7. 편집_프로젝트/      .prproj, 자막(SRT)
  8. 출력/               검수본_v##, 최종본
```
규칙:
- 씬 폴더 이름은 대본 S#와 같게(`#1` = S#1). **대본에 없는 추가 컷은 `추가1`, `추가2`**로 따로 두고, 어느 씬에 쓸지 작업 기록표에 적는다.
- 파일명 `S##-C##-설명-v##` + 도구 약칭(선택): `S04-C02-문답시연-v03-seedance.mp4`.
- 씬 폴더 안에 `_채택` 폴더를 만들어 편집에 쓸 테이크만 옮긴다. 나머지는 지우지 말고 둔다(재편집 대비).
- 폴더 대표 이미지(썸네일)가 그 씬 컷이 되도록 채택 이미지를 맨 앞에 두면 탐색기에서 바로 찾는다.
- 프리미어 빈(Bin)도 같은 구조로 만들어 디스크 폴더와 1:1로 맞춘다.
- 하루 작업이 끝나면 클라우드/외장 드라이브에 백업한다.

요청 시 출력: 이 작품용 폴더 트리, 현재 소재 목록에서 빠진 컷(대본 대비 누락) 점검표.

## 8-2. 시퀀스와 트랙 배치
- 시퀀스: 1920×1080(또는 3840×2160), **24fps**, 오디오 48kHz. 생성 영상 fps가 다르면 해석(Interpret Footage)으로 맞춘다.
- 트랙:
  | 트랙 | 내용 |
  |---|---|
  | V1 | 메인 영상(스튜디오·드라마 INS) |
  | V2 | 자료 INS, 인서트 |
  | V3 | 자막·연도 표기·출처 |
  | A1 | 대사(립싱크·V.O.) |
  | A2 | 효과음 |
  | A3 | 음악 |

## 8-3. 편집 순서
1. **대사로 뼈대**: A1에 대사를 대본 순서대로 깔고 길이를 확정한다(라디오 편집).
2. 대사에 맞춰 V1 컷 배치. 립싱크 컷은 프레임 단위로 싱크 확인.
3. V2 인서트로 설명을 대신한다(말하는 동안 자료 INS로 컷어웨이).
4. **J컷/L컷**: 다음 씬 소리를 0.5~1초 먼저 들어오게 해 전환을 부드럽게.
5. 효과음 → 음악 순서로 얹는다. 대사 구간은 음악 덕킹.
6. 색 맞춤: 컷마다 다른 AI 생성 톤을 Lumetri로 통일(바이블의 톤 & 룩 기준). 필름 그레인을 전체에 얇게 깔면 컷 간 차이가 줄어든다.
7. 자막: 대사 자막 + 연도/장소 표기 + 고증 자료 출처. AI 영상에서 깨진 글자·숫자는 여기서 그래픽으로 덮는다.

## 8-4. 믹싱 기준
- 대사 피크 -6 ~ -10dB, 음악은 대사 아래 -18 ~ -24dB, 앰비언스는 들릴락 말락.
- 최종 라우드니스: 유튜브/온라인 **-14 LUFS**, 방송 납품 -24 LKFS(국내 기준 확인).

## 8-5. 출력과 최종 체크리스트
- H.264, 원본 해상도, 24fps, 고비트레이트(1080p 16~20Mbps 이상). 보관용 마스터는 ProRes.
- 체크:
  - [ ] 대사·자막 오탈자, 립싱크 어긋남
  - [ ] 컷 간 의상·조명·소품 연속성
  - [ ] 얼굴·손·텍스트 왜곡 컷 제거 또는 가림
  - [ ] 실사 고증 자료 출처 표기, "AI로 생성된 재연 영상" 고지
  - [ ] 음악·효과음 사용권
  - [ ] 총 길이가 목표와 맞는지

## 출력
요청에 따라: 폴더/파일명 정리표, 편집 순서표(타임코드·트랙·소재), 자막 파일(SRT) 초안, 최종 체크리스트.
